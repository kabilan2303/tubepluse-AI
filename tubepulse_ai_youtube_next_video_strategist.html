Connect Live YouTube Data API v3

Analyze any real public YouTube channel directly in your browser

Why is an API key required for live URLs?

YouTube blocks direct browser scraping via CORS. To retrieve accurate, real-time public video titles, upload dates, view counts, and engagement metrics for any channel URL, TubePulse uses the official Google YouTube Data API v3.

  1. Open the Google Cloud Console & enable YouTube Data API v3.
  2. Create an API Key under Credentials and paste it below.
  3. Your key stays strictly in your browser memory for this session.
